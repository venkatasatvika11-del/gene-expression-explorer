# 🧬 Gene Expression Data Explorer

A lightweight, interactive **Streamlit** app for exploring CSV-based gene
expression data — built as a demo for a **Python & Biopython workshop**.

Upload your own gene expression CSV (or use the included synthetic dataset)
and explore it through:

- **📋 Data Table** — browse and search all genes, download filtered results
- **🔍 Gene Lookup** — view a single gene's expression across sample groups (box plot)
- **🌋 Differential Expression** — volcano plot with adjustable log2FC / p-value thresholds
- **🔥 Heatmap** — top variable genes, row z-scored
- **📊 PCA** — principal component analysis of samples, colored by group

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/gene-expression-explorer.git
cd gene-expression-explorer
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run app/app.py
```

The app will open in your browser at `http://localhost:8501`.

## Using Your Own Data

The app expects a CSV where:
- Each **row** is a gene
- Each **column** is either a gene identifier (e.g. `GeneID`, `GeneSymbol`)
  or a numeric sample (e.g. `Control_1`, `Treatment_1`)

Example:

| GeneID | GeneSymbol | Control_1 | Control_2 | Treatment_1 | Treatment_2 |
|--------|------------|-----------|-----------|--------------|--------------|
| ENSG1  | TP53       | 8.2       | 8.5       | 6.1          | 6.4          |

Upload your CSV via the sidebar, then assign which columns belong to
**Group A** and **Group B** for comparison.

> 💡 Expression values are assumed to already be on a log2 scale (e.g. log2 TPM/CPM),
> since fold change is computed as a simple difference of group means.

## Sample Dataset

`data/gene_expression_sample.csv` contains a **synthetic** dataset of 300
genes × 12 samples (6 Control, 6 Treatment), generated by
`data/generate_sample_data.py`. About 15% of genes are seeded with a real
differential expression signal so the volcano plot, heatmap, and PCA all show
meaningful structure out of the box. Regenerate it any time with:

```bash
python data/generate_sample_data.py
```

## Workshop Context

This project was built as part of a **Python & Biopython workshop**,
demonstrating how a few common Python libraries (`pandas`, `numpy`, `scipy`,
`plotly`, `streamlit`) can turn a plain CSV of gene expression values into an
interactive exploration tool — a common early step in bioinformatics/RNA-seq
analysis pipelines before moving on to tools like Biopython, DESeq2, or
edgeR.
